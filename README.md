# BluHExH Portfolio

Personal portfolio website for [BluHExH](https://github.com/BluHExH) — Open Source Developer & Security Researcher.

Dark, technical aesthetic inspired by modern cybersecurity dashboards.

## Stack

- React 19 + TypeScript
- Vite 8
- Pure CSS (no Tailwind dependency)
- Google Fonts: Rajdhani, Inter, JetBrains Mono

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Live on Vercel after connecting this repo.
